# HR Analytics Dashboard – Employee Attrition Analysis

## 📌 Project Overview
This project analyzes employee attrition trends and workforce demographics using Power BI. The dashboard helps HR teams identify departments with high attrition, understand employee distribution, and improve workforce planning.

## Business Problem
Organizations often struggle to identify the reasons behind employee attrition. This project helps analyze attrition trends based on department, age, gender, and education background to support HR decision-making.

## 🛠 Tools & Technologies
- Power BI
- DAX
- Data Visualization
- Data Cleaning

  ## Key KPIs
- Total Employees
- Attrition Count
- Attrition Rate
- Active Employees
- Average Employee Age

  ## 📊 Dashboard Features
- Department-wise Attrition
- Gender-wise Analysis
- Age Group Distribution
- Education Field Analysis
- Job Role Analysis
- Interactive Filters

## 💡 Business Insights
- R&D department showed the highest attrition.
- Employees aged 25–34 had higher attrition.
- Male employees contributed slightly higher attrition.
- Life Sciences employees showed higher turnover.
- Senior employees had better retention rates.

  ## Business Impact
This dashboard helps HR teams identify high-risk employee groups and improve retention strategies using data-driven insights.
